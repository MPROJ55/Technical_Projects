# Technical Projects

A collection of hands-on technical projects focused on infrastructure,
networking, automation, AI systems, and home lab experimentation.

This repository documents projects I'm building to strengthen my practical
experience with the technologies and concepts used in modern IT,
infrastructure, networking, and AI engineering.

## Home Lab & Infrastructure

My home lab is primarily built around **Proxmox VE** and is used to experiment
with virtualization, infrastructure design, and network services.

Current and planned areas of work include:

- Proxmox VE virtualization
- Virtual machines and containers
- Load balancer configuration and testing
- Reverse proxies
- High-availability concepts
- Linux server administration
- Infrastructure monitoring
- Self-hosted services
- Infrastructure automation
